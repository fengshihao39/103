## AI 使用说明

本项目在开发过程中使用了 Claude（Anthropic）作为辅助工具。

**AI 完成的部分**
- 解析 rosbag 数据，找出其中的异常（NaN、inf、超速、尖峰、中断）
- 提出双节点架构与 Topic 设计
- 编写两个节点的 C++ 代码、launch 文件与参数文件
- 撰写 README 初稿

**本人完成的部分**
- 搭建 Docker + ROS 2 Humble 开发环境，创建 Git 仓库
- 编译、运行与测试，逐步排查问题（如多次启动导致同一 topic 出现多个发布者、残留节点清理、rqt_graph 中 topic 被隐藏等）
- 对照实际运行输出验证 README 中的时间线与统计数据，修正与实测不符之处
- 录制运行视频，整理提交

**学习收获**
- 通过追问理解了 NaN/inf 在 IEEE 754 中的含义，以及它们为何会绕过普通的限速判断
- 理解了"订阅回调更新目标值、定时器负责发布"的设计，以及看门狗超时机制的作用
